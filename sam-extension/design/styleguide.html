Color

Components never reference the primitive ramp. They use the semantic names, which is what makes a theme swap possible without touching a single component rule. Ratios below are computed live against the surface each pairing actually lands on — the same arithmetic npm run contrast runs in CI.

Semantic text on surfaces

Intent

Surfaces

Violet is reserved. It marks FedRAMP / GovCloud IL2 and nothing else. Using it for ordinary emphasis erodes the one signal that tells an operator they are about to change an audited environment.

Typography

Six sizes. The pre-system popup had drifted to ten, several separated by half a point — differences that read as sloppiness rather than hierarchy at this scale.

Space & radius

A 4px base with 2px half-steps. Dense controls genuinely need the half-steps; prefer the even values everywhere else.

Elevation & motion

--shadow-raised
--shadow-modal

Durations live in tokens so prefers-reduced-motion can zero every animation in the system from one place. Nothing in a component may declare a raw duration; the linter fails the build if it does.

  • --dur-fast 120ms — hover and colour transitions
  • --dur-med 200ms — toast entry
  • --dur-spin 700ms — one spinner revolution
  • --dur-shimmer 1.4s — one skeleton pass

Forms

Control borders are an accessibility requirement

--line-strong outlines anything the user has to find and click, and clears 3:1 against every surface it can sit on (WCAG 1.4.11). --line only separates regions, so it is exempt and stays subtle. Using the wrong one is the single easiest way to fail an audit.

A Notice describes the whole session and spans the popup edge to edge. A Callout describes the field beside it and is inset. Do not substitute one for the other.

Destructive confirm
